## Self-service from Company Portal

Most software is available in **Company Portal**, the self-service app on every company laptop.
Search for the application and select **Install**. No ticket or approval is needed for anything
listed in Company Portal, including browsers, Zoom, Slack, VS Code, Python, Node.js and 7-Zip.

## Software that is not in Company Portal

Raise a software request ticket with the product name, version, vendor website and what you need
it for. IT Security reviews new software for security and licensing, which takes up to **5 business
days**. If approved, IT adds it to Company Portal so others can install it too.

Do not download and install software yourself from the internet; company laptops block unapproved
installers.

## Paid software

Paid software needs a licence; see the Software Licences guide. Do not buy software with a personal
card and claim it on expenses.

## Updates

Windows, macOS and Company Portal applications update automatically. Restart your laptop at least
once a week so updates can finish. If an application reports that it is out of date and will not
update, raise an application error ticket with a screenshot of the message.

## Application errors

For an application that crashes or shows an error, first restart the application and then the
laptop. If the problem continues, raise a ticket that includes the application name, the exact
error message and when it started.
